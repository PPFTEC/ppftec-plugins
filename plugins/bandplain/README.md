# bandplain

Claude Code plugin from PPFTEC S.R.L. It connects Claude to the Bandplain remote MCP server at `https://bandplain.ppftec.com/mcp` and adds a short skill that tells Claude when to use it and which tool to call first. Sign-in, when a tool needs it, is handled by Claude through OAuth; the plugin stores no keys. Results are general information with dated official sources, not legal advice.

- Docs: https://bandplain.ppftec.com/mcp/docs/
- Privacy: https://bandplain.ppftec.com/privacy/mcp/

Install: `/plugin marketplace add PPFTEC/ppftec-plugins` then `/plugin install bandplain@ppftec`.
