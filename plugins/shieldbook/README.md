# shieldbook

Claude Code plugin from PPFTEC S.R.L. It connects Claude to the Shieldbook remote MCP server at `https://shieldbook.ppftec.com/mcp` and adds a short skill that tells Claude when to use it and which tool to call first. Sign-in, when a tool needs it, is handled by Claude through OAuth; the plugin stores no keys. Results are general information with dated official sources, not legal advice.

- Docs: https://shieldbook.ppftec.com/mcp
- Privacy: https://shieldbook.ppftec.com/privacy

Install: `/plugin marketplace add PPFTEC/ppftec-plugins` then `/plugin install shieldbook@ppftec`.
